═══════════════════════════════════════════════════════════════════════════

1️⃣  ABRA O ARQUIVO
    Clique em: index.html

    Seu navegador abrirá a loja online completa!


2️⃣  EXPLORE A INTERFACE
    ✓ Scroll pelas 10 seções
    ✓ Observe os efeitos hover
    ✓ Clique nos botões
    ✓ Interaja com os cards


3️⃣  TESTE AS FUNCIONALIDADES
    ✓ Adicione produtos ao carrinho
    ✓ Favorite produtos (❤️)
    ✓ Use a barra de busca
    ✓ Faça login/logout


4️⃣  ABRA O CONSOLE (F12)
    Execute um dos comandos:
    
    > showCart()              ← Ver carrinho
    > showFavorites()         ← Ver favoritos

5️⃣  RECARREGUE A PÁGINA
    Seus dados continuam salvos! ✨

🛒 COMO USAR O CARRINHO
═══════════════════════════════════════════════════════════════════════════

1. Clique em "+ Carrinho" nos produtos
2. Veja a notificação ✓ verde
3. Abra console (F12)
4. Execute: showCart()
5. Veja seu carrinho com total

Os dados ficam salvos automaticamente!


❤️ COMO FAVORITAR
═══════════════════════════════════════════════════════════════════════════

1. Clique no ícone 🤍 (branco)
2. Ele muda para ❤️ (vermelho)
3. Abra console (F12)
4. Execute: showFavorites()
5. Veja lista de favoritos

Seus favoritos continuam mesmo após reload!


🔍 COMO BUSCAR
═══════════════════════════════════════════════════════════════════════════

1. Digite na barra de busca (topo)
2. Digite qualquer termo (ex: "camisa")
3. Abra console (F12)
4. Veja os resultados
5. Digite Enter para confirmar


🔐 LOGIN/LOGOUT
═══════════════════════════════════════════════════════════════════════════

1. Clique no botão "entrar" (topo direito)
2. Ele muda para "sair"
3. Clique novamente para logout
4. Status persiste entre recargas
